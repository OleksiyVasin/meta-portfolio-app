# Oleksiy Vasin — Portfolio

Single-page React portfolio with a header, landing bio, featured projects, and a contact form.

## Requirements

- [Node.js](https://nodejs.org/) (LTS) and npm

`node_modules` is not included. Install dependencies locally before running the app.

## Install

From the project folder:

```bash
npm install
```

## Start

```bash
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).
